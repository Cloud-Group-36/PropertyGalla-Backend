About PropertyGalla

PropertyGalla is a backend system for a real estate platform that supports user authentication, property listings, feedback, and agent management via a RESTful API.
It is built with ASP.NET Core and deployed using various AWS services, including Elastic Beanstalk, S3, Lambda, RDS, and API Gateway.
The system employs JWT for secure authentication and role-based access control to ensure user security.
Technologies Used

    Backend Framework: ASP.NET Core

    Database: Amazon RDS (MySQL)

    Authentication: JWT (JSON Web Tokens)

    File Storage: Amazon S3

    Compute: AWS Lambda

    API Gateway: AWS API Gateway

    Deployment: AWS Elastic Beanstalk

    Networking: Amazon VPC

    Security: Role-based access control
